Enter a Memo and Save Without Opening the App

Benefits

This shortcut saves logs in the same way as saving from the main app.
If you want to record a memo that isn’t already registered, you can enter text directly without switching screens — making logging smoother.

How to set up

  1. Open the Settings app → Shortcuts → enable "Allow Untrusted Shortcuts".

    * If this option does not appear on your iOS version, skip this step.

  2. Get the shortcut from the button below.

    Get shortcut from here (tap twice)

    Open the Shortcuts app and find “Record Time — Input Memo”.

  3. The first time you run the shortcut, you will see a message asking for access to the TimeStamp app. Tap Allow / OK.
