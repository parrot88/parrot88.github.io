Select an item from your custom list to record it instantly

Benefits

You can create a list of entries you frequently record and simply pick one from the widget or shortcut.
This saves you time because you don’t have to type a memo every time you log something.

How to set up

  1. Open the Settings app → Shortcuts → enable "Allow Untrusted Shortcuts".

    * If this option does not appear on your iOS version, skip this step.

  2. Get the shortcut from the button below.

    Get shortcut from here (tap twice)

    Open the Shortcuts app and find “Record Time from List”. Edit the preset list items to customize them as you like.

  3. The first time you run the shortcut, you will see a message asking for access to the TimeStamp app. Tap Allow / OK.
