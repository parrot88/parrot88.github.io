Save Using a Registered Memo

Benefits

With this shortcut, you can save a log by just tapping the Shortcut button — no typing required.
You can also edit preset memo texts and place the shortcut on your Home Screen for easy access.

How to set up

  1. Open the Settings app → Shortcuts → enable "Allow Untrusted Shortcuts".

    * If this option does not appear on your iOS version, skip this step.

  2. Get the shortcut from the button below.

    Get shortcut from here (tap twice)

    Open the Shortcuts app and find “Record Time with Memo”. Edit the text in “Enter what you want to record here” to customize the memo.

  3. The first time you run the shortcut, you will see a message asking for access to the TimeStamp app. Tap Allow / OK.
