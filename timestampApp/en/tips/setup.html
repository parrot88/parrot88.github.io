How to set up shortcuts (common steps)

Every shortcut on this site is set up the same way.

What you need

  • TimeStamp app
  • Shortcuts app (built into iPhone)

Steps

  1. Open the Settings app → Shortcuts → enable "Allow Untrusted Shortcuts".

    * If this option does not appear on your iOS version, skip this step.

  2. Tap the "Get shortcut" button on each tip page. The shortcut is added to your Shortcuts app.

  3. The first time you run the shortcut, you will see a message asking for access to the TimeStamp app. Tap Allow / OK.

Put icons on your Home Screen (recommended)

Shortcuts can be added to the Home Screen as icons. Keeping them on one screen makes recording much faster.
Search for "iPhone add shortcut to home screen" to see how.

Want to tweak a shortcut?

Shortcuts can be edited. Search for "edit iPhone shortcut" and customize it for yourself.
If something breaks, just get the shortcut again from its page.
